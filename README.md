# Прыг-Крок 🐊

Прототип браузерной игры: крокодильчик прыгает по блокам и собирает штучки.
Чем выше блок, тем больше очков. Упал — игра окончена.

## Структура

```
croc-streamlit/
├── app.py              # Streamlit-приложение, встраивает игру
├── requirements.txt    # зависимости (только streamlit)
├── static/
│   └── game.html       # сама игра (HTML5 Canvas + JS)
└── README.md
```

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run app.py
```

Откроется http://localhost:8501

## Деплой в Streamlit Community Cloud

1. Создай репозиторий на GitHub и загрузи туда содержимое этой папки
   (`app.py`, `requirements.txt`, папку `static`).
2. Зайди на https://share.streamlit.io и войди через GitHub.
3. Нажми **Create app** → **Deploy a public app from GitHub**.
4. Выбери репозиторий, ветку `main`, в поле **Main file path** укажи `app.py`.
5. Нажми **Deploy**. Через 1–2 минуты приложение будет доступно по ссылке
   вида `https://<имя>.streamlit.app`.

После каждого `git push` приложение обновляется автоматически.

## Уровни

- Всего 10 уровней. Очки копятся непрерывно: 2-й уровень начинается с 1000 очков,
  3-й — с 2000 и так далее, 10-й — с 9000.
- На новом уровне меняется только фон (закат, туман, полдень, осень, гроза,
  лунная ночь, северное сияние, рассвет, вулканы, звёздный финал), блоки и
  правила те же. Смена фона плавная, в центре на пару секунд появляется надпись.
- В правом верхнем углу под очками — номер уровня и полоска прогресса до следующего.
- 10 000 очков — 10-й уровень пройден, появляется экран «Победа!» с кнопкой «Играть снова».
- Порог и число уровней задаются в `static/game.html`: константы `LEVEL_PTS`
  и `MAX_LEVEL`, фоны — массив `THEMES`.

## Мобильная версия

- На телефоне под игрой появляется панель кнопок: ◀ ▶ бег, ▲ прыжок.
  Тап по игровому полю тоже работает как прыжок (удержание — прыжок выше).
- На узком экране (вертикальная ориентация) мир автоматически отдаляется,
  чтобы было видно следующие блоки; в горизонтальной видно ещё больше.
- В горизонтальной ориентации шапка Streamlit, заголовок и подсказка скрываются,
  а окно игры подгоняется ровно под высоту экрана — кнопки внизу всегда видны.
- Страница прокручивается свайпом по заставке, экрану «Плюх!» и свободной части
  панели кнопок. Во время игры свайп по игровому полю и по кнопкам страницу не двигает.
- Отключён двойной тап-зум.

## Заметки

- Игра работает полностью в браузере, сервер только отдаёт страницу —
  нагрузки на Streamlit почти нет.
- Чтобы управлять с клавиатуры, нужно один раз кликнуть по игре
  (она находится внутри iframe).
- Рекорд хранится в браузере игрока; если браузер блокирует хранилище
  в iframe, рекорд просто не сохранится между сессиями.
- Высоту окна игры можно поменять в `app.py` (константа `GAME_HEIGHT`).
